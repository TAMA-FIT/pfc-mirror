たまフィットPFC 緊急ミラー版（2026-08-26）

目的:
- GitHubアカウント停止によるGitHub Pages停止からアプリを退避するための静的ミラー。
- 元アプリと同じlocalStorageキーを使用し、既存バックアップJSONをそのまま読み込める。
- GASのWebアプリURLは元アプリの ai.js に記録されている現行URLを維持。
- 公開不要なGASサーバーソース/APIキー、.git、開発用ファイルは配布物から除外。
- Service Workerを実キャッシュ化し、一度正常表示した後は主要UIをオフラインでも開けるように変更。

既存データの移行:
1. 旧アプリがまだ開ける場合:
   設定 -> バックアップ保存 -> pfc_backup_YYYY-MM-DD.json を保存。
2. 新ミラーを開く。
3. 設定 -> バックアップ読込 から上記JSONを選択。
4. 食事履歴、当日データ、My食品、お気に入り、PFC目標、体組成などが移行される。

注意:
- 旧アプリのデータ本体はサーバーではなく、その端末・ブラウザのlocalStorageに保存されている。
- 体型写真はIndexedDBに別保存され、元のバックアップJSONには含まれない。写真救出は別手順が必要。
- 新しい公開URLは旧GitHub Pagesとは別originになるため、ブラウザが旧localStorageを自動で新サイトへ渡すことはできない。
